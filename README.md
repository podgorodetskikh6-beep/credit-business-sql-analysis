# Оценка эффективности каналов привлечения кредитного бизнеса

## О проекте

Анализ кредитного бизнеса с использованием SQL.

Цель проекта — оценить эффективность каналов привлечения, надежность платежей, кредитную воронку, сегменты клиентов и качество продуктов.

## Стек

- SQL

## Анализ

Пример того, что рассчитано в рамках проекта:

- количество заявок;
- уровень одобрения;
- количество выданных кредитов;
- объем выдач;
- количество успешных оплат;
- средний DPD;
- доля проблемных кредитов;
- стоимость одной заявки;
- эффективность каналов привлечения;
- эффективность кредитных продуктов.

## SQL

В проекте использованы:

- JOIN/LEFT JOIN
- CASE WHEN
- COUNT DISTINCT
- агрегатные функции
- NULLIF / COALESCE

## Результат

На основе анализа были определены наиболее эффективные
каналы привлечения и сегменты кредитного бизнеса с учетом
объема выдач, стоимости привлечения и качества кредитного
портфеля.
